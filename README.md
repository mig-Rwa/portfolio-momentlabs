# Photography Portfolio Website

A modern, responsive photography portfolio website for a Rwandan photographer based in Norway. This website showcases the photographer's work with a clean and elegant design.

## Features

- Responsive design that works on all devices
- Modern and clean UI
- Smooth scrolling navigation
- Interactive gallery
- Contact form
- Social media integration
- Optimized for performance

## Customization

### 1. Content Updates

#### Gallery Images
To update the gallery images, modify the `galleryImages` array in `script.js`. Replace the sample images with your actual photos:

```javascript
const galleryImages = [
    {
        src: 'path/to/your/image.jpg',
        title: 'Your Image Title',
        description: 'Your image description'
    },
    // Add more images as needed
];
```

#### About Section
Edit the text in the `about` section of `index.html` to reflect your personal story and experience.

#### Contact Information
Update the contact information in the `contact` section of `index.html` with your actual details:
- Email address
- Phone number
- Location

### 2. Styling

The website's colors and styling can be modified in `styles.css`. Key color variables to customize:
- Primary color: `#3498db`
- Secondary color: `#2c3e50`
- Background colors
- Text colors

### 3. Social Media Links

Update the social media links in the footer section of `index.html` with your actual social media profiles.

## Getting Started

1. Clone or download this repository
2. Open `index.html` in your web browser
3. Start customizing the content and styling to match your needs

## Browser Support

The website is compatible with all modern browsers:
- Chrome
- Firefox
- Safari
- Edge
